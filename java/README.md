## LTS Release Summary

| LTS Version | Released | Key Additions |
|-------------|---------|---------------|
| Java 8 | Mar 2014 | Lambdas, Streams, Optional, `java.time`, CompletableFuture |
| Java 11 | Sep 2018 | HTTP Client, String methods, `var` in lambdas, single-file programs |
| Java 17 | Sep 2021 | Sealed classes, pattern matching switch (preview), strong JDK encapsulation |
| Java 21 | Sep 2023 | Virtual threads, sequenced collections, record patterns, switch patterns, structured concurrency (preview) |
| Java 25 | Sep 2025 | Upcoming LTS |
